# Casa Azul — The Life of Frida Kahlo

An interactive, scroll-driven tribute to Frida Kahlo, inspired by the aesthetics of
her home and museum, **La Casa Azul** in Coyoacán. Each chapter pairs a short,
poetic passage with photographs and artworks you can **click to turn over** and
read an anecdote from her life.

> The stories here are concise summaries written for this site, and the artwork is
> illustrative placeholder work (not Frida Kahlo's own) — meant to be swapped for
> rights-cleared photography and refined biography later.

## Tech

- [Astro](https://astro.build/) — static site, ships almost no JavaScript
- [Tailwind CSS v4](https://tailwindcss.com/) — Casa Azul design tokens in `src/styles/global.css`
- Vanilla JS for the flip cards and gentle scroll-reveal (with reduced-motion support)
- Deployed to GitHub Pages, with a live preview on every pull request

## Develop

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static build into dist/
npm run preview  # serve the build locally
```

## Editing content

- **Stories & captions:** `src/data/chapters.ts` — one entry per chapter, each with
  cards (`img`, `caption`, `storyTitle`, `story`).
- **Artwork:** drop real images into `public/art/` and point the `img` paths at them.
  The placeholder SVGs are generated by `node scripts/gen-art.mjs`.
- **Look & feel:** colors, fonts, and the flip-card styling live in
  `src/styles/global.css`.

## Deployment

`/.github/workflows/deploy.yml` builds the site and:

- on push to `main`, publishes the production site to GitHub Pages
- on each pull request, publishes a preview to `…/pr-preview/pr-<n>/` and comments
  the link on the PR

GitHub Pages must be enabled with the **gh-pages** branch as the source.
